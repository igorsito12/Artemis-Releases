# Artemis

Instaladores e atualizações da aplicação Artemis.

## Instalar no Windows

Abre a [versão mais recente](https://github.com/igorsito12/Artemis-Releases/releases/latest) e descarrega o instalador `.exe`.

## Atualizações na aplicação

A partir da versão 0.1.6, a aplicação consulta este canal ao abrir. Também podes procurar atualizações nas definições. A instalação pede confirmação.

Quem tiver uma versão anterior deve instalar a 0.1.6 manualmente uma vez para passar a usar este canal.

Cada versão disponibiliza o instalador, a assinatura de verificação do atualizador (`.sig`), os hashes SHA-256 e o manifesto `latest.json`.

Este repositório destina-se à distribuição dos instaladores. O desenvolvimento e o código-fonte são mantidos separadamente.
